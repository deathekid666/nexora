# NEXORA

Phase 1 prototype for an interactive technology marketplace.

## Current build

- Responsive marketplace shell
- Flagship iPhone 17 Pro Max product experience
- Interactive 3D device using React Three Fiber
- Finish/color switching
- Exploded/anatomy views for display, cameras, processor and battery
- Structured quick specifications
- Comparison UI
- Reusable category concept for phones, TVs, laptops, consoles, wearables and accessories

## Stack

- Next.js
- TypeScript
- React Three Fiber / Three.js
- Drei
- GSAP (installed for upcoming scroll-driven sequences)
- Shopify / Stripe integrations planned after the product experience is validated
- Vercel deployment target

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

Preview branch: full LHAWTA product detail pages and linked catalog cards.
